# 小鸡说 AI 网站分析与功能清单

## 1. 界面结构

目标网站采用典型的 AI 创作工作台布局：顶部是任务与账号区，左侧是产品功能导航，中间是参数编辑区，右侧是大面积实时效果预览。视觉以白色、浅灰和低饱和蓝紫为主，边界和阴影都很克制，信息密度高但层级清楚。

详情页主流程是：上传商品图 → 选择平台规范 → 填写卖点 → 选择页面模块 → 一键生成 → 预览与导出。

## 2. 公开页面可见功能

### 电商创作

- 商品底图：生成或替换商品背景
- 商品详情页：生成主视觉、卖点、场景、角度、氛围和细节图
- 海外电商：面向海外平台的商品内容
- 设计海报：AI 海报设计
- 爆款 IP 分析：分析热门内容或 IP
- 爆款视频：视频生成或爆款视频工作流
- 数字人：数字人内容生成
- 发布编辑器：编辑并发布生成内容

### 趣味与效率工具

- AI 看相
- AI PPT

### 账号与内容管理

- 登录、注册、找回密码
- 个人中心与点数购买
- 草稿箱、搜索、分类筛选、重命名、删除
- 云端归档
- 新建任务及当前任务状态

## 3. 商品详情页的具体参数

- 商品原图：本地上传或链接导入，同一商品最多 3 张
- 平台：亚马逊、淘宝/天猫、京东、小红书、Shopify、TikTok、自定义
- 国家/地区：美国、中国、日本、韩国、欧洲、东南亚
- 语言：英文、中文、日文、韩文
- 页面类型：普通 A+、高级 A+、品牌故事
- 商品卖点：支持预览、复制、清空和 AI 辅写
- 模块多选：首屏主视觉、核心卖点图、使用场景图、多角度图、场景氛围图、商品细节图

## 4. 生图接口分析

- Base URL：`https://xiaoji.baziapi.site/v1`
- 鉴权：`Authorization: Bearer sk-jp-xxx`
- 提交：`POST /images/generations`
- 查询：`GET /images/generations/{task_id}`
- 推荐模型：`gpt-image-2`
- 参考图：`reference_images`，支持 URL 或 Data URL，最多 8 张
- 生成张数：`n=1..4`，每张图对应一个独立异步任务
- 推荐每 2-5 秒查询一次，直到 `completed` 或 `failed`
- 完成后优先读取 `url` 或 `image_url`，也兼容 `data[0].url`

当前项目已经完成接口代理、任务提交和轮询。只需在 `.env` 中加入 `XIAOJI_API_KEY` 即可调用，密钥不会暴露在前端。
